## 移动端（iOS / PlayCover）

画面变体：`assets/game_data/mobile/screen_info/menu.yml`。变体加载规则见 [macOS 支持设计](../../develop/one_dragon/macos_playcover_design.md)。实拍归档 `screens/菜单/移动端.webp`。

- 入口：大世界左上角 `ME` 按钮（@90,40-235,140）。
- 左上角返回是红色箭头（模板 `mobile_menu/back` @80,20-205,110），和地图、其它画面的返回按钮相同。
- 底部一排图标加文字：更多 / 勘域编队 / 邮件 / 设置 / 公告 / 成就 / 绳网 / 仓库 / 代理人 / 商城 / 丽都城募 / 调频（@60,1005-1860,1062）。比 PC 多出最左侧的「更多」，**没有「快捷手册」入口**（移动端从大世界顶部图标进快捷手册）。
- 没有 PC 的动态壁纸按钮。
- 识别标记：返回模板 + 底部「邮件」「更多」文字。返回按钮在很多画面都有，只靠它会误判。
