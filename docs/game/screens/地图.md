# 地图

> 普通传送(`MapTransport`)的 **2D 列表传送画面**。**传送机制**(两种地图区别 / 入口按 `N` / 传送点类型 / 传送行为)见 [mechanics/传送](../mechanics/传送.md);本 doc 记画面识别 + 本画面传送流程。

## 子态流转

| 子态 | 入口 | 出口 |
|---|---|---|
| ⓪ 区域选择 default 态 | 按 `N` 进(见 mechanics) | 点区域(澄辉坪/…)→ ① |
| ① 选传送点(列表) | 选区域后底部出传送点列表(随便观/阿朔/汀曼咖啡…) | 点传送点 → ② |
| ② 传送确认弹窗 | 点传送点 → 弹「是否传送至该地点？」(确认/取消) | 点「确认」(`地图/确认` area)→ 传送落地;取消 → 回① |

> `MapTransport` 流程(`src/zzz_od/operation/map_transport.py`):整屏 OCR 后按 `地图/主区域名称` 过滤结果并选区域 → 整屏 OCR 后按 `地图/传送点名称` 过滤结果并选传送点 → 点确认(`click_tp`,`地图/确认`)。

## 识别特征(稳定锚点)

- **传送点名称** area(@70,1000-1848,1058,底部传送点列表,无 text)。
- **主区域名称** area(@0,90-1920,930,主区域列表,排除底部传送点名称)。
- **确认** area(@1024,600-1232,708,text`确认`,弹窗绿√按钮)。
- **左上角返回**(template `menu/back` @82,13-150,90)。
- **易变值**:传送点名称 / 当前选择(**动态**)。

## 可交互元素

- 传送点列表(点传送点 → 弹确认)。
- 确认 / 取消(确认弹窗)。
- 左上返回。

## 识别快照

### 0. 区域选择 default 态(`区域选择.webp`,2026-07-18 实拍)

按 `N` 后出**主区域列表**(澄辉坪/六分街/斯科特哨站/热望角/光映广场/奥蕾莉亚学院/[空洞]航天城/…),横向排列 + drag 切换。点区域(澄辉坪 `526,592`)→ 底部出传送点列表(①)。主区域保持整屏 OCR，只允许落在 `地图/主区域名称` 内的结果参与匹配，避免把底部「录像店营业点」模糊匹配成主区域「录像店」。

### 1. 选传送点态(`选传送点.webp`,2026-07-15 实拍)

点区域(澄辉坪)后底部出传送点列表。整屏 OCR 后只保留 `地图/传送点名称` 内的结果，再从当前主区域的传送点名单中匹配随便观 / 阿朔 / 汀曼咖啡 / 录像店营业点 / 饮茶仙 / 临界推演。点传送点 → ②。

### 2. 传送确认弹窗态(`传送确认弹窗.webp`,2026-07-15 实拍)

点传送点后弹「是否传送至该地点？」+ 确认(绿√ @1101,609,`地图/确认` area @1024,600-1232,708)+ 取消(红× @798,610)。点确认 → 传送落地。

## 移动端（iOS / PlayCover）

画面变体：`assets/game_data/mobile/screen_info/map.yml`。变体加载规则见 [macOS 支持设计](../../develop/one_dragon/macos_playcover_design.md)。实拍归档 `screens/地图/移动端-区域选择.webp`、`移动端-传送确认弹窗.webp`。

- 入口：大世界小地图右下方的圆形「信号」按钮（模板 `mobile_normal_world/map` @1630,308-1730,408），对应 `大世界/地图` 区域。
- 区域选择和选传送点在同一个画面：上方是区域卡片网格（每行 3 张，区域名在卡片右下角，当前区域黄框，右侧 `>` 翻页），底部一行是当前区域的传送点（如录像店：H.D.D. / 影像档案架 / 柜台 / 房间 / 车库）。
- 区域范围：`主区域名称` @0,120-1920,880；`传送点名称` @30,995-1890,1052。
- 传送确认弹窗：「是否传送至该地点？」+ 取消（@790,650）/ 确认（`地图/确认` @980,610-1320,690）。
- 左上角返回是和菜单相同的红色箭头。
- `Transport` 的地图识别（区域名 ≥3 + 传送点 ≥1 + 左上角返回）在移动端可以直接使用。
