# 快捷手册

绝区零**玩法总入口**(绝大多数周期 / 常驻玩法的统一入口)。大世界右上角「快捷手册」按钮进。5 个 TAB(目标 / 日常 / 训练 / 作战 / 战术),每 TAB 列玩法卡片(玩法名 + 奖励进度 + 「前往」传送按钮)。

**为什么重要**:式舆防卫战 / 迷失之地 / 零号空洞 / 危局强袭战 / 咖啡店 / 影像店 / ... 等玩法入口都在这里;app `TransportByCompendium(tab, category, mission_type)` 经此传送。

## 何时出现 + 状态流转

- **入口**:大世界 右上「快捷手册」按钮(~1531,60,需 pc_alt)→ 快捷手册。
- **流转**:选 TAB → 点玩法卡片「前往」→ 传送确认「是否立即传送?」→ 点「确认」→ 传送到该玩法入口。
- **退出**:esc / 左上返回 → 大世界。

**TAB 切换**(顶部,y~161):目标(769)/ 日常(955)/ 训练(1142)/ 作战(1330)/ 战术(1514)。

## 识别特征(稳定锚点)

- **TAB 文字**:目标 / 日常 / 训练 / 作战 / 战术(顶部,稳定;TAB-XX text area)。
- **QUICK ... HANDBOOK**(左上标题)。
- **资源栏**(右上角):三段右对齐数字 —— 电量(3 位,如 240/240)、储蓄电量(4 位上限 2400)、以太电池数(3 位上限)。`ChargePlanApp.check_battery_charge` 运行「电量检测」图像分析流水线:按「快捷手册->以太电池」区域裁剪,再做 HSV 过滤,最后整栏 OCR;取数时以 `/` 分界取左段数字,按检测框中心与三个字段的固定中心锚点比对归位,缺字段补 0。同一栏另有「以太电池」模板 area(battery 图标)。

## 移动端（iOS / PlayCover）

画面变体：`assets/game_data/mobile/screen_info/compendium_*.yml`（目标 / 日常 / 训练 / 作战 / 战术 五个 TAB 画面）。变体加载规则见 [macOS 支持设计](../../develop/one_dragon/macos_playcover_design.md)。实拍归档 `screens/快捷手册/移动端-*TAB.webp`。

- 入口：大世界顶部图标栏里带 Z 的文档图标（模板 `mobile_normal_world/compendium` @1428,62-1505,134）。**默认打开「目标」TAB**（PC 默认训练），路由会再点一次 TAB 切到目标画面。
- TAB 顺序：目标 / 日常 / 训练 / 作战 / 战术，文字中心 x 约 789 / 988 / 1187 / 1387 / 1586，y 约 156。每个 TAB 是独立按钮。
- 选中的 TAB 是**黄底黑字**（PC 是黄字）。识别标记按黄色背景过滤：只有选中 TAB 留下黄底，文字以空洞形式被 OCR 读出。区域只框住文字附近，避开 TAB 左上角同为黄色的 `NEW!` 角标。
- 关闭是右上角红色 ×（@1772,215-1850,295）。
- 资源栏（电量等）在右上角，位置和 PC 不同，`快捷手册` 画面里的列表、资源栏等区域还没有移动端变体。
